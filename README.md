# Saturation Fix for Farm & Charm and Brewery

An unofficial fix for **Minecraft 1.21.1 / NeoForge**: food from **[Let's Do] Farm & Charm** and
**[Let's Do] Brewery** gives far too little saturation. For example, an Oat Pancake gives 0.6
saturation instead of 6.0, and Goulash gives 0.8 instead of 22.4.

With this mod installed, those foods give the saturation their configs describe, and **AppleSkin
shows the correct values**.

- Fixes 35 foods (27 from Farm & Charm, 8 from Brewery).
- Respects your config: if you change a food's saturation in the mod's config, the fix uses it.
- Placed meals eaten in bites stay correct too.
- **Switches itself off** once the bug is fixed in Farm & Charm and Brewery, so it is safe to keep
  installed through updates.
- Contains no code or assets from Farm & Charm or Brewery. Both are required and must be installed
  separately.

## Requirements

| | Version |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1 or newer |
| [Let's Do] Farm & Charm | 1.1 or newer (tested against 1.1.29) |
| [Let's Do] Brewery (Farm&Charm Compat) | 2.1 or newer (tested against 2.1.13) |

Install it on **both** the client and the server.
